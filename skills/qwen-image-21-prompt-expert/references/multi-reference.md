# Multi-reference editing

Use alongside `edit-policy.md` when at least two images enter Qwen-Image 2.1. Confirm the destination workflow's slot order before writing the prompt. In this user's AstrBot plugin and saved edit workflow, `<image1>` is the target canvas; `<image2>` and, in the plugin, `<image3>` are reference sources. The base model may support more images elsewhere; that does not raise the plugin's three-image limit.

Establish a role map before writing: which image supplies the subject or identity, which supplies clothing/pose/style/background/objects, and whether the result edits image 1 or builds a genuinely new scene. Then use the exact supported markers, `<image1>`, `<image2>`, `<image3>`, in the final instruction for every source that matters. Do not swap the canvas merely because the user mentions the source image first; instead follow the workflow's actual target order or tell the caller to reorder images.

Lead with a single, clear relationship: for example, put the garment from `<image2>` on the person in `<image1>`, or apply the lighting of `<image2>` to `<image1>`. Describe source-image details only if visible and decision-relevant. Keep identity, pose, framing, background, and medium when an ordinary local transfer should preserve them; drop a preservation clause whenever it conflicts with the requested change. A new composition assembled from several references needs explicit positions, interactions, and depth, not a command to preserve the original canvas unchanged.

For multiple people, identify each person by image slot and spatial role. Do not collapse two source identities into one face, invent a third person, or treat a clothing reference as a second character unless requested. When the reference contains several plausible source objects, specify the intended one or ask which one to use. Exact visible text follows the user's wording and source role.

The user's tested clothing-transfer backbone is: “Put the clothing from `<image2>` onto the character in `<image1>`, replacing the current outfit. Keep the character's identity and the unchanged pose, framing, background, lighting, and art style. Reproduce the visible garment design and fit it naturally.” Adapt or omit these clauses for non-clothing edits; this is not a universal wrapper.

The local edit workflow's first-image aspect ratio and 1 MiP cap are settings, not prompt instructions. If a reference is too small, clipped, or ambiguous, say so rather than promising that extra prose guarantees fidelity. Community [source/target examples](https://www.reddit.com/r/StableDiffusion/comments/1wlt9t9/qwen_image_21_edit_tips/) are useful trial patterns; [official model documentation](https://github.com/QwenLM/Qwen-Image-2.1) and the [ComfyUI edit template](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_qwen_image_2_1_image_edit.json) define supported capabilities and the current workflow contract.
